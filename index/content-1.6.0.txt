[groups.ltx]
; Content bundle layout for Dead Air: Refined.
;
; Content is split into bundles so that changing one texture re-publishes one bundle instead
; of the whole set. A bundle is an .xdb0 archive whose filename carries the SHA-256 of the
; packed file, so unchanged content keeps its name and is never re-uploaded or re-downloaded.
;
; THE ASSIGNMENT TABLE BELOW IS APPEND-ONLY.
; Editing or removing a line moves files between bundles, which changes both bundles' bytes,
; which changes both filenames - and every installed player re-downloads both. New directories
; are appended automatically by the builder into the smallest shard of their group; that edit
; is committed and reviewed like any other, but existing lines are never touched.
;
; Sharding is an explicit directory table rather than `hash % shard_count` precisely because
; the shard count WILL grow: a modulo scheme re-shuffles every file the moment it changes, so
; a single new bundle would cost a full re-download of everything.

; A shard aims for this size. It is a target, not a limit: a directory is never split across
; shards, so one oversized directory produces one oversized bundle (the builder warns).
